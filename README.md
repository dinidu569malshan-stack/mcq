# MCQ Quiz App

A simple and responsive Multiple Choice Question (MCQ) quiz application built with HTML, CSS and JavaScript.

## Features

- 10 ICT-related MCQ questions
- 4 answer choices per question
- 15-second timer for every question
- Instant correct/wrong answer feedback
- Live score counter
- Quiz progress bar
- Final result screen
- Restart quiz button
- Responsive black and gold design

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How to Run

1. Clone or download the repository.
2. Open `index.html` in a web browser.
